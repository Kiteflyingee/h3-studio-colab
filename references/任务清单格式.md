# 任务清单格式

统一单任务/流水线清单顶层包含非空 `jobs` 数组，按顺序执行；引用前序主输出使用 `@job_id`。

| `type` | 必填 / 主要字段 | 默认锁定配置（`profile`） |
|---|---|---|
| `image` | `prompt`；可选 `inputs`（最多 8 张）、`aspect`、`size`、`upsample`、`align_to_first`、`align_mask` | `ph3-lora-int8`（或 `ph3-standalone-w4a8`） |
| `video` | `prompt`、`mode`、`seconds`（2–15 秒）；`inputs` 或 `first`/`last` 或 `extend`/`guides`/`control` | `text`/`frames`: `h3-fl2va-int8`；`ref`/`extend`: `h3-ref2va-int8`；`guides`: `h3-guides`；`control`: `h3-control-union` |
| `video_edit` | `source_video`、`seconds`、`anchors:[{frame, image}]`（1–16 张已确认锚点图）；可选 `comparison`、`crop`、`megapixels` | `h3-ripple`（6 步 LCM） |
| `tts` | `prompt`、`seconds`（2–15 秒）；可选 `voices`（最多 3 段参考音） | `h3-tts32-native` |
| `voice_replace` | `source_video`、`voice`、`options:{start, end, replace, trim_voice}` | `media-only`（CPU） |
| `subtitle_replace` | `source_video`、`plan:{subtitles, overlays, clear_regions, font}` | `media-only`（CPU） |
| `media_copy` | `source_video` | `media-only`（CPU） |

- `video.extend` 指向前序 ID 或源视频文件；`extension_output="segment"` 仅输出新增片段，`"cumulative"` 输出拼接累计片（新增时长 + 22 帧上下文须 ≤15 秒）。
- `video.mode="guides"` 提供 `guides:[{at_seconds, image}]`（时间递增且位于片段内）。`mode="control"` 提供 `control:{kind, video, mask, preprocess}`（Colab 在线预处理内置 `canny`，其余传 `preprocess: false` 的已预处理视频）。
- 整片爆款复刻请求格式见 `examples/remake-v3.json`；单段 Ripple 锚点扩散见 `examples/ripple-anchors-v3.json`；多步串联见 `examples/advanced-v3.json`。
