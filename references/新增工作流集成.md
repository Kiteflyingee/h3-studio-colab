# 模型路线与环境准备

本项目只保留经过版本锁定的 **MiniMax H3 原生模型体系 + WepeNerd H3 Ripple**，已彻底移除跨生态冗余分支（Wan / VACE / CSR / ReActor / 旧版残缺 PRISM）。

| 能力模块 | 锁定配置（`profile`） | 核心节点与特点 |
|---|---|---|
| 文生视频 / 首尾帧视频 | `h3-fl2va-int8` | 原生 `MiniMaxH3ImageToVideo` + 8 步 Turbo LoRA |
| 多模态参考视频 / 续接 | `h3-ref2va-int8` | 原生 `MiniMaxH3ReferenceToVideo` + `MiniMaxH3AddGuide` |
| 多时间点关键帧引导 | `h3-guides` | `Ref2VA` + 多点 `MiniMaxH3AddGuide` |
| 空间控制视频 | `h3-control-union` | `Ref2VA` + `MiniMaxH3FunControlNetApply`（内置 `canny` 在线预处理） |
| 爆款复刻关键帧改图（Step 1） | `ph3-lora-int8` | `PH3ImageConditioning` + `QwenEditAlignComposite` 仿射对齐还原背景 |
| 爆款复刻关键帧扩散（Step 2） | `h3-ripple` | `WN_RippleFromFrames → WN_RippleApply → WN_RippleOutput`，复用同一 `FL2VA` 底模，6 步 LCM |
| 独立轻量生图 | `ph3-standalone-w4a8` | 独立 W4A8 图像模型，无需加载 FL2VA 底模 |
| 配音与参考音色克隆 | `h3-tts32-native` | 原生 H3 音频生成，支持最多 3 段参考音色 |
| 可选采样加速 | `fasth3-omni-int8` / `prism-dmad-pdmd-int8` | 独立 8 步加速模型配置 |
| 后期音字合成 | `media-only` | 纯 FFmpeg/CPU 执行字幕、叠字与时段混音 |

所有权重仓库、revision、SHA256 与许可链接记录在 `models/catalog.json`；ComfyUI 与 `WepeNerd/ComfyUI-WepeNerd` 的固定 commit 记录在 `dependencies.lock.json`，在 Colab 新会话中按任务自动安装与校验。
