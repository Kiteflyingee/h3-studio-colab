# 操作指南

1. 在已登录 Colab CLI 的终端运行 `python scripts/h3studio.py check` 检查登录与剩余点数。
2. **爆款视频复刻（同镜改人/改物）**严格执行两步确认法：
   - 第一步：`python scripts/h3studio.py remake-anchors request.json --gpu L4 --allow-unverified`，检查下载回来的 `anchors/*_compare.jpg`（左原帧、右改后帧）。某张锚点需重抽时传 `--session NAME --only remake_001_anchor1`。
   - 第二步：确认关键帧满意后运行 `python scripts/h3studio.py remake-render request.json --session NAME --confirmed --allow-unverified --output final.mp4`，由 `WepeNerd H3 Ripple` 6 步扩散全片并合成配音/字幕。
   - 若做跨画风/跨物种重制（如真人转 2D 拟人猫动画），设 `"mode": "recreate"` 直接运行 `remake-render`。
3. **原创多镜头短片**：先用 `director-compile` 导出 `timeline.html` 核对分镜，再用 `director-render --confirmed --output final.mp4` 远端渲染合片。
4. **单件生成与后期处理**：统一运行 `python scripts/h3studio.py run job/manifest.json --gpu L4 --allow-unverified`。断线恢复加 `--resume`；单任务重做加 `--only ID`（连带下游加 `--with-dependents`）；`uncertain` 状态先查服务队列，禁止盲目重投。
5. 批次完成后询问用户是否继续微调；不再使用时运行 `python scripts/h3studio.py stop --session NAME`（或 `stop --all`）立即释放 GPU 省点。
