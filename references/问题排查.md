# 常见问题排查

| 现象 | 原因与解决办法 |
|---|---|
| **忘记关机担心持续扣点** | 每次结束工作前运行 `python scripts/h3studio.py sessions` 查看，并用 `python scripts/h3studio.py stop --all` 一键释放所有云端实例。正常跑完的实例默认由后台看门狗在空闲 15 分钟后自动释放。 |
| **Colab 提示 `503 Service Unavailable` 或分配不到 GPU** | 晚高峰常见资源紧张，不会开机也不会扣点。稍等片刻重试，或在 `--gpu L4`、`--gpu G4`、`--gpu A100` 之间切换。 |
| **执行 `remake-render` 提示缺少已确认的关键帧** | 爆款同镜复刻默认启用两步保护机制：请先执行 `python scripts/h3studio.py remake-anchors <request.json> --gpu L4 --allow-unverified`，检查回传的 `*_compare.jpg` 确认形象无误后再执行 `remake-render`。 |
| **某一段或某一张关键帧效果不理想** | 无需整批重跑：加上 `--session <SESSION> --only <任务ID>`（若有下游任务同时加 `--with-dependents`）即可在热机上秒级单点重做。 |
| **网络波动或终端断开** | 使用完全相同的清单/请求加上 `--resume` 重新执行，执行器会校验 `prompt_id` 与文件 SHA256 自动续传，不会重复提交正在运行的推理。 |
| **参考图片或参考视频未生效** | 检查 `prompt` 中是否明确写了 `@图片1`、`@视频1`、`@音频1`（序号按同类素材在 `inputs` 中的位置从 1 开始计算）。 |
| **生成视频底部出现意外烧录字幕** | 提示词描述过短：请参考 `references/提示词指南.md` 补全英文镜头、环境与连续动作描述。 |
| **`A100` 上视频解码崩溃** | 本技能已在 `--gpu A100` 时自动将视频 VAE 切换为 `minimax_h3_video_vae_fp16.safetensors`（H3 Ripple 默认亦使用 `fp16` VAE），避免 `int8_convrot` 在 SM80 架构上的非法显存访问。 |
